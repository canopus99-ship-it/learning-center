# 평생학습센터 회원관리 시스템

회원 등록 / 강좌 관리 / 수강신청 / 수납 / 출석 / 통계 기능을 제공하는 웹 시스템입니다.

## 2단계: 로그인 시스템 추가

- Google OAuth 로그인 (jlcwc.or.kr 도메인)
- 직원 명단 관리 (관리자/태블릿 권한)
- 로그인 안 한 사용자 자동 차단
- 관리자만 직원 명단 수정 가능

## 1단계: 회원 등록 (이전)

- 회원 신규 등록
- 주민번호 → 생년월일/성별 자동 추출
- 거주지 → 중구민/타구민 자동 판별
- 서류확인 다중 체크
- 등록된 회원 목록 조회
